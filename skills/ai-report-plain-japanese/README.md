# AI報告書「伝わる日本語」Skill v1.1

AIが作成する報告書・分析資料・提案書を、**専門性や正確性を維持したまま、専門外の読者にも自然に伝わる日本語**へ編集するSkillです。

「中学生でも分かる」は子ども向けの語彙や文体にすることではなく、読み手が余計な推測や解読をしなくても、話の背景から結論まで理解できる状態を指します。

## 特徴
- 背景と前提を補い、話の出発点を明確にする
- 根拠から結論までの論理の飛躍を見つける
- 数値の測定条件・比較対象・業務上の意味を示す
- 専門用語を必要な場所だけで簡潔に説明する
- AIの直訳調、不自然な受動態、冗長表現を改善する
- 元の情報、留保、数値、確度を改変しない

## 使い方
Skillを利用できるAIエージェントのSkillディレクトリに、`skills/ai-report-plain-japanese/` を配置してください。

指示例：
> ai-report-plain-japaneseを使って、専門性を落とさず背景から結論まで自然に理解できる報告書に直してください。

## 既存Skillとの使い分け
- `japanese-business-quality`：自然で正確なビジネス日本語への校正
- `ai-report-plain-japanese`：背景・論理・説明の不足を解消し、報告書全体を一読で理解できるようにする

## ファイル構成
- `skills/ai-report-plain-japanese/SKILL.md`：実行手順、文体基準、評価項目、例文
- `skills/ai-report-plain-japanese/README.md`：導入方法と使い分け
